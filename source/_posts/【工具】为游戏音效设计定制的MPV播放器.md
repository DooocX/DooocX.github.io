# 为游戏音效设计定制的视频播放器

在游戏音效设计与审核的日常工作流中，常规媒体播放器往往无法满足专业需求。例如，系统自带播放器在格式切换时存在延迟，部分播放器快捷键配置不够灵活，而使用专业音频工作站（DAW）打开短素材又显得过于繁重。这些工具并非专为“审核”这一特定环节设计。

为此，基于 mpv.net 定制了一款专为音效设计工作流优化的视频播放器。其核心原则为：**所见即所得，无任何附加渲染**——确保画面直出、音频原样呈现，同时快捷键逻辑完全围绕“反复聆听、精准查看、快速切片”展开。


### 一、为什么要使用定制版播放器？

市面上的常规播放器在音效设计场景中普遍存在以下痛点：

- **默认附加后处理**：许多播放器会自动开启混响、均衡器或画面锐化，导致视听效果与游戏引擎内的实际表现产生偏差。
- **跳转响应迟缓**：部分播放器在加载视频或切换文件时存在明显卡顿，影响工作效率。
- **跳转精度不足**：音效审核常需要反复聆听极短（如 200ms）的片段，而多数播放器仅支持 5 秒或 10 秒的粗粒度跳转。
- **格式兼容性有限**：面对 .mkv、VP9、FLAC 等多样化素材，常规播放器可能无法正常解码。
- **切片流程繁琐**：若仅需截取视频片段用于演示，通常需要借助剪辑软件进行处理和重新导出，耗时较长。


**什么是 MPV？**
> MPV 是一款开源、跨平台的极简媒体播放器，源自 MPlayer / mplayer2 分支，专注于高画质视频播放与专业审片场景。它采用命令行内核 + libmpv 库架构，支持 GPU 加速渲染（gpu-next / D3D11 / Vulkan）、硬件解码（nvdec / dxva2）、HDR、10bit、8K 播放，并通过 Lua/JavaScript 脚本、IPC 接口和高度可配置的 mpv.conf / input.conf 提供极强的扩展性。轻量、无广告、纯净直出画面，是发烧友与音视频从业者的首选播放引擎。


### 二、精准跳转：逐帧与多级步进

音效审核最频繁的操作是反复查看或聆听特定短片段，因此跳转精度至关重要：

| 操作 | 按键 | 粒度 |
|---|---|---|
| 逐帧前进 / 后退 | `,` / `.` | **1 帧** |
| 小步跳 | `←` / `→` | **1 秒**（精确 seek） |
| 中步跳 | `Shift+←` / `Shift+→` | **5 秒** |
| 大步跳 | `↑` / `↓` | **10 秒** |
| 超大步 | `Ctrl+←` / `Ctrl+→` | **30 秒** |

> 所有的跳转操作均附加了 `exact` 参数，确保精准定位至目标帧而非最近的关键帧，这对于音频波形的精确对齐具有重要意义。

**`Home` / `End`** 键可快速跳转至首尾，点击进度条任意位置即可直接跳转。该跳转逻辑覆盖了从“逐帧对齐波形”到“快速浏览长视频”的各类场景。


### 三、AB 循环：片段反复聆听

在审核素材时，常需要对极短的音频片段（如枪声尾音衰减）进行反复确认。

- 按 **`l`** 键设置 A 点（起点），再次按键设置 B 点（终点），第三次按键即可清除循环区间。
- 按 **`L`** 键可切换无限循环播放。

结合 1 秒/5 秒的精确跳转与逐帧步进功能，可实现极高精度的循环区间设定。


### 四、变速播放：慢速细节审查

部分音效瑕疵（如爆音、咔嗒声或转场衔接不自然）在慢放状态下更易被察觉：

| 按键 | 效果 |
|---|---|
| `[` / `]` | 减速 / 加速 **10%** |
| `{` / `}` | **半速** / **双速** |
| `Backspace` | 恢复 **1x** |

> 变速播放**不会改变音高**。播放器内部采用 `scaletempo2` 算法，在 0.5x 至 2x 的变速范围内，听感保持清晰，无明显相位失真，这是许多通用播放器难以实现的。


### 五、无损切片：免重编码快速导出

音效设计过程中，常需从长视频或实机录像中截取片段。传统流程需要导入剪辑软件并重新渲染，效率较低。

本定制版集成了快速切片功能：

| 键 | 作用 |
|---|---|
| **`h`** | 设起点 |
| **`k`** | 设终点 |
| **`e`** | 导出 |

采用 `-c copy` 模式，**无需重新编码**，可实现瞬间切片。导出文件将自动编号并保存在源文件同级目录下。视频起点会自动回落至最近的 I 帧，音频部分则不受影响。


### 六、视听直通：无损原始呈现

在审核素材时，核心需求是观察素材的**原始状态**，而非经过播放器“美化”后的效果。锐化、降噪、色调映射等处理在一定程度上会改变画面本质，导致播放器内的效果与引擎最终呈现不一致，从而失去审核的准确性。

音频方面同样遵循此原则：配置 `video-sync=audio` 以音频时钟为基准，避免为对齐显示器刷新率而进行重采样；配置 `interpolation=no` 禁用插帧，保留原始帧率。**确保输出的音频为文件内原始的 PCM 数据。** HDR 视频的直出则交由系统色彩管理处理。

> 若显卡与 nvdec 存在兼容性问题（如黑屏或花屏），可将 `mpv.conf` 中的 `hwdec=nvdec` 修改为 `hwdec=no`。在现代 CPU 上，软件解码通常也能流畅运行。


### 七、字幕与截图：辅助审核工具

在审核带有字幕的素材时，默认字幕样式配置为**微软雅黑 45pt 金黄色 + 深色描边**，确保高辨识度，避免与画面内容混淆：

```ini
sub-font=Microsoft YaHei
sub-font-size=45
sub-color=#fbc420
sub-border-color=#000000
sub-border-size=2.5
```

截图功能提供三种模式：

| 按键 | 内容 |
|---|---|
| `s` | 带字幕 + OSD |
| `S` | 纯净画面 |
| `Ctrl+s` | 带窗口装饰 |

截图格式为 PNG，文件名自动附加时间戳与序号（格式：`文件名_时间戳_序号.png`）。在提交 Bug 或反馈时，可直接使用纯净画面截图，省去二次裁剪的步骤。


### 八、信息显示：参数排查与诊断

按 **`i`** 键可唤出持久统计面板（stats.lua），实时查看以下信息：

- 当前视频/音频的编码格式、码率、分辨率、帧率
- 解码器类型（硬件解码/软件解码）
- 丢帧数量、渲染延迟
- 音频采样率、声道布局

按 **`I`** 键可显示单次统计信息，按 **`o`** 键可显示播放进度条。

当遇到素材无法播放的情况时，可通过 `i` 键快速查看编码格式，以便排查是否使用了不支持的编码器。


### 九、播放列表与自动加载

打开任意视频文件后，同目录下的其他音视频文件将**自动加入播放列表**，当前文件播放完毕后会自动切换至下一个。

- 按 `TAB` 键可呼出或关闭播放列表面板。
- 在列表打开状态下，使用**方向键**进行导航。
- 按 `Backspace` 键可将选定文件从列表中移除。

此功能在批量审核同一文件夹内的素材时极大提升了便利性。


### 十、冷启动性能优化

为提升启动速度，播放器进行了以下底层配置优化：

- `resume-playback=no`：禁用续播记录扫描，在记录较多时可节省数百毫秒的启动时间。
- `force-window=immediate`：双击后立即创建窗口，无需等待首帧就绪，显著提升视觉响应速度。
- 启用 `hwdec=nvdec`（不附加 `-copy`）：减少 GPU 到 CPU 的数据回拷，实现文件切换的无缝衔接。
- `demuxer-max-bytes=64MiB`：降低预读缓存，加快首帧渲染速度。

通过上述优化，播放器实现了极低的启动延迟。

### 总结

该定制版播放器的定位非常明确：**它并非旨在替代 DAW 或专业剪辑软件，而是专为素材审核环节打造的轻量化工具**。它具备快速、精准、无干扰的特点，能够高效融入音效设计的日常工作流。

所有配置文件均集成在 `portable_config/` 目录下，解压即用，无需修改系统注册表，支持跨设备便携使用。
