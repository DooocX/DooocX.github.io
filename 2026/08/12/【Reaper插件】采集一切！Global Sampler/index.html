这玩意是干啥的？

用一句话概括：它一直在后台循环录音，你任何时候都能把刚刚听到的东西拖回工程里。

无论你在 REAPER 里干什么 — 调参数、试效果器、搓带（scrubbing）、预览素材 — 它都在默默记录。默认保留最近 60 秒的音频，波形实时显示在 GUI 里，觉得哪段不错，直接框选、拖进工程，完事。

对声音设计师来说，这就是一颗”后悔药”：你再也不用担心刚才随手拧出来的那个酷炫声音找不回来了。

它能干什么？几个实实在在的场景

场景一：瞎拧参数时抓到一个好声音

你在调一个 synth 音色，随便拖动各种旋钮，突然出来一个巨好听的瞬间 — 但你根本记不住是哪些参数组合。有了 Global Sampler，波形窗口里那段音频就在那，框选，拖进工程，永久保存。

场景二：预览素材时发现宝藏

在 Media Explorer 里快速浏览一堆采样，偶然听到一个片段叠在工程里效果出奇地好。正常流程你得记住文件名、找到它、拖进来 — Global Sampler 直接拖那段实时录下来的音频就行。

场景三：搓带搓出的意外惊喜

Scrubbing 的时候经常会搓出一些诡异的、有意思的声音片段。Global Sampler 放在 Monitor FX 链上，连搓带的声音都能录到。

场景四：免 GUI 快速导出

它还配了两个辅助脚本：

  • BirdBird_Sample Last Playthrough.lua：自动导入上一次你按下播放到停止期间听到的全部音频
  • BirdBird_Sample Last X Seconds.lua：导入最近 X 秒（上限 60 秒）的音频到编辑光标位置

不需要打开 GUI，一键操作，非常适合快节奏的工作流。

怎么装？

需要三个前置依赖：

  1. **SWS 扩展**（REAPER 必备扩展，大概率你已经装了）
  2. **ReaPack**（脚本包管理器）
  3. **js_ReaScriptAPI**（ReaPack 里直接装）

粘贴以下仓库地址：

然后在 ReaPack 里搜索 Global Sampler，安装 BirdBird_Global Sampler.lua。

怎么用？

第一步：插入 JSFX 插件

打开 FX 浏览器，在 JS 分类下搜 Global Sampler，插入到以下任一位置：

位置 能录到什么 推荐程度
Monitor FX 所有输出 + 搓带 + 预览 ⭐⭐⭐ 首选
Master Track 项目混合后输出 ⭐⭐
任意轨道 该轨道信号 ⭐

推荐放 Monitor FX — 这样它就是个”全局常驻”方案，不用每个工程都手动加。

第二步：运行脚本

Actions → 搜 BirdBird_Global Sampler.lua → Run。

GUI 窗口一出来，JSFX 就开始录了。

停靠到 REAPER 主窗口

停靠位置、主题、缩放级别都会自动记住。还可以用 BirdBird_Global Sampler Theme Editor.lua 自定义主题。

注意事项

  • 这是 alpha 版本，可能有 bug
  • 一个会话里只能放一个 JSFX 实例，多了会出问题
  • 切换项目标签页通常没问题，脚本会自行处理
  • 如果你想让录制时长超过 60 秒，可以手动改 JSFX 文件里的 len_in_secs 值（但不建议，可能导致内存问题）

免费版 vs 付费版

作者后来推出了一个独立插件版 **Rolling Sampler**：

Global Sampler (脚本) Rolling Sampler (插件)
价格 永久免费 $19
录制时长 60 秒 最长 10 分钟
多实例 ❌ ✅
停靠 ✅ ❌
跨 DAW REAPER 专属 任何 DAW

脚本版完全够用，付费版适合对多实例和更长录制时间有需求的用户。

总结

Global Sampler 属于那种”装上就回不去”的工具。占用资源极小，日常使用时你甚至感觉不到它的存在 — 直到你突然需要刚才那个”一晃而过”的声音，它就在那等着你。
