# DocX Audio Blog

基于 **Hexo 7.3.0 + Quiet 主题**（深度定制）搭建的个人博客与游戏音频作品集，部署在 GitHub Pages。

- 🌐 **访问地址**：https://docxaudioblog.top
- 📚 **内容方向**：游戏音频设计、Wwise 笔记、工具分享、SHOWREEL 作品集

---

## 快速开始

```bash
# 安装依赖
npm install

# 本地预览
hexo clean
hexo server
# 打开 http://localhost:4000

# 部署
hexo deploy
```

---

## 主要功能

- ✍️ **博客文章**：Markdown 撰写，支持代码高亮 / 图片懒加载 / 灯箱预览
- 🎬 **SHOWREEL 作品集**：音效设计作品展示，支持 B 站 iframe / mp4 双视频源
- 🌓 **暗色模式**：跟随系统偏好 + 手动切换 + localStorage 持久化
- 💬 **Giscus 评论**：基于 GitHub Discussions，主题与站点暗色同步
- 📖 **文章目录 (TOC)**：悬浮左侧，滚动高亮，宽屏自动显示
- 📱 **响应式**：桌面 / 平板 / 移动端三档适配
