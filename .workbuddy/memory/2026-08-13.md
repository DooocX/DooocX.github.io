## 图床日常管理（DocX 追问）
- 删除：七牛控制台「对象存储→doxcxblogimage→文件管理」勾选删除最稳（支持批量/搜索/前缀筛选）。⚠️ 纠正：PicGo 原生不支持图床远端同步删除（官方 FAQ 明确），不存在可靠的 picgo-plugin-qiniu-delete 插件，PicGo 相册删除只删本地记录、不删云端。批量删可用七牛官方 CLI qshell，或 Python qiniu SDK 脚本（bucket.delete）。
- 自动命名：PicGo 已开「时间戳重命名」（文件名 20260813175822344.png 即证据），在 设置→详细设置 勾选。想自定义规则（前缀/哈希/格式）装 picgo-plugin-rename-file。
- 分类文件夹：七牛图床「设定存储路径」是写死单字段（当前 test/），不能按上传动态变。优雅做法=时间戳命名 + 语义前缀（如 wwise-git-...png），或写小插件自动把 path 设为 YYYY/MM/。
